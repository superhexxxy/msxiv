msxiv

fast, keyboard-driven image viewer for macOS. native swift. zero deps.

$ msxiv ~/Pictures $ msxiv -t ~/Wallpapers $ msxiv photo.jpg
install source

features

[K]

keyboard-driven

navigate, zoom, rotate, manage. vim-style bindings throughout.

[>]

native and fast

swift + appkit. no electron, no gtk, no qt. apple silicon optimized.

[#]

thumbnail grid

toggle between image view and thumbnail grid. one keystroke.

[&]

scriptable hooks

key handlers, window titles, image info via shell scripts.

[*]

mark and select

mark files, copy paths, trash with confirm. batch workflows.

[~]

minimal

does one thing well. no telemetry. no bloat. just an image viewer.

installation

requires macOS 13+ and xcode command line tools.

from source

git clone https://github.com/superhexxxy/msxiv.git
cd msxiv
./install.sh

via homebrew

brew tap superhexxxy/tap
brew install msxiv

then set up the config: mkdir -p ~/.config/msxiv && cp /opt/homebrew/etc/msxiv/config ~/.config/msxiv/config

optional: config

make install-config

scripting

msxiv works with shell scripts. here are some things you can do:

open in preview with ; key

create ~/.config/msxiv/key-handler:

#!/bin/sh
while read file; do
  open -a "Preview" "$file"
done

copy marked files

press x to mark, then ; to copy:

#!/bin/sh
mkdir -p ~/Pictures/Selected
while read file; do
  cp "$file" ~/Pictures/Selected/
done

show exif in status bar

create ~/.config/msxiv/image-info:

#!/bin/sh
file="$1"
exif=$(exiftool -Model -DateTimeOriginal "$file" 2>/dev/null)
echo "$exif"

upload to cloud

#!/bin/sh
while read file; do
  curl -F "file=@$file" https://0x0.st | pbcopy
  osascript -e "display notification \"URL copied!\" with title \"msxiv\""
done

set wallpaper

#!/bin/sh
while read file; do
  osascript -e "tell application \"Finder\" to set desktop picture to POSIX file \"$file\""
done

keybindings

keyaction
h j k lpan and navigate
space / rightnext image
leftprevious image
g / Gfirst / last
ttoggle thumbnails
ffullscreen
w / Wfit image / fit window
1100% zoom
+ / -zoom in / out
r / Rrotate (view / save)
xmark file
ccopy path
oopen in default app
dtrash (confirm)
stoggle slideshow
;run key-handler
qquit

configuration

config at ~/.config/msxiv/config

thumbnail_size = 128
zoom_increment = 1.25
background_color = #282828
status_bar = true
sort_by = name
recursive = false
slideshow_delay = 3.0
